# Retail Sales Analytics & Forecasting — Streamlit Prototype

## Included
- CSV and Excel upload
- Automatic Date/Sales column detection
- Data cleaning and validation
- KPI dashboard
- Daily sales trend
- Category-wise sales
- Region-wise sales
- Initial 7-day moving-average forecasting prototype
- Business insights and recommendations
- Data preview / quality section
- Sample CSV and Excel dataset

## Run locally

1. Install Python 3.10+.
2. Open Command Prompt / Terminal in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the app:

```bash
streamlit run app.py
```

The browser will open the Streamlit dashboard automatically.
